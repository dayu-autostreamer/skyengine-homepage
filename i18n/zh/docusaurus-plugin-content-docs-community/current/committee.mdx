认识参与天工项目协调，以及仿真、调度、实验和文档维护的成员。

## 项目主席 {#project-chair}

<CommunityMembers role="chair" />

项目交流与研究合作可通过[项目联系人](./support.mdx#project-contact)沟通。

## 维护者 {#maintainers}

<CommunityMembers role="maintainer" />

技术问题与修改建议可在相关 Issue 或 Pull Request 中与维护者讨论。请说明涉及的组件、预期行为，以及有助于理解问题的实验或运行结果。

## 参与贡献 {#participate}

你可以通过代码、文档、实验、评审或可复现的问题报告参与项目。从[参与贡献](./contributing.md)了解如何选择仓库并准备修改。

[贡献者与致谢](./contributors.mdx)介绍项目贡献者；需要寻找交流渠道时，可参考[支持与联系](./support.mdx)。
