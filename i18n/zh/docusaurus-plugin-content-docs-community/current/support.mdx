## 问题与贡献 {#questions}

| 问题类型 | 反馈入口 |
| --- | --- |
| 安装或初次使用 | 先阅读[快速开始](/docs/getting-started/installation/)，再通过[天工 Issues](https://github.com/dayu-autostreamer/skyengine/issues)提问。 |
| 工厂行为、算法、实验或平台问题 | 在[天工系统仓库](https://github.com/dayu-autostreamer/skyengine/issues)提交 Issue。 |
| 网站内容、导航或翻译 | 通过[网站 Issues](https://github.com/dayu-autostreamer/skyengine-homepage/issues)反馈。 |
| 参与贡献、设计讨论或寻找评审者 | 阅读[参与贡献](./contributing.md)，在相关 Issue 或 Pull Request 中与[维护者](./committee.mdx#maintainers)交流。 |
| 项目交流或研究合作 | 使用下方的[项目联系渠道](#project-contact)。 |

## 反馈可复现的问题 {#report-a-problem}

请提供足够的信息，便于其他人复现：

- 天工版本或提交号、操作系统、部署方式与计算设备配置。
- 工厂环境、实例或数据集、算法、相关参数与随机种子。
- 复现步骤、预期行为和实际结果。
- 相关日志、错误信息或导出的运行记录。

反馈实验结果时，请同时说明完成率、仿真步数上限和耗时指标。反馈网站问题时，请附上页面地址、语言、浏览器和受影响的内容。
