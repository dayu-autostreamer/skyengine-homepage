天工将**实验工作流**、**工厂执行**与**算法决策**分开，使不同算法可以在共同的仿真环境中运行。

```text
用户界面
工厂管理 · 实时看板 · 日志分析 · 算法实验
                     │
平台服务
运行控制 · 实验编排 · 模型管理 · 结果管理
                     │
工厂仿真
作业 · 机器 · AGV · 道路 · 物料 · 动态扰动
                     ↕
算法组件
工序调度 · 任务分配 · 路径规划 · 联合调度策略
```

## 平台与工厂生命周期

Vue 前端与 FastAPI 后端交互。工厂代理提供初始化、启动、暂停、重置、清理等生命周期操作，以及状态、指标与控制信息流。后端按环境类型选择代理。

容器化网格工厂由 `DockerProxy` 连接仿真和算法服务；PacketFactory 使用单独的代理与配置流程。共享生命周期方法，不意味着底层环境可以直接互换。

## 仿真与算法决策

网格环境的协调器连接三类职责：

| 组件 | 职责 |
| --- | --- |
| 工序求解器（Job solver） | 决定加工工序与机器安排 |
| 任务分配器（Task assigner） | 将运输任务分配给车辆 |
| 路径求解器（Route solver） | 决定车辆在道路网络中的移动 |

联合调度策略可以同时考虑生产和运输。DFJSP-T 策略内置 PIBT 执行车辆移动，训练和模型测试不需要另选 MAPF 算法。

工厂始终负责合法移动、加工推进、缓冲容量、物料交接和完成判定。最后一道工序加工结束并不等于订单完成：成品运抵成品站并完成卸货后，订单才计为完成。

## 实验与证据

算法实验工作台组织训练、参数探索和测试，模型与检查点将训练连接到独立测试。事件记录、数据集结果和过程回放帮助解释仿真中发生的事情。

训练、验证／调优和最终 benchmark 数据应相互独立。比较时保持实例、随机种子、扰动和仿真步数上限一致。

| --- | --- |
| `skyengine` | 平台、前端、仿真与实验基础设施 |
| `SkyEngine-FJSP` | 工序调度算法及其 HTTP 容器服务 |
| `SkyEngine-MAPF` | 多智能体路径规划算法及其 HTTP 容器服务 |
| `skyengine-DFJSPT` | `dfjsp_t_rl` Python 包与联合调度训练组件 |
