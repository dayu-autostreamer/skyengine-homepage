## Questions and contributions {#questions}

| Topic | Where to go |
| --- | --- |
| Installation or first use | Start with the [quick start](/docs/getting-started/installation/), then ask in [SkyEngine issues](https://github.com/dayu-autostreamer/skyengine/issues). |
| Factory behavior, algorithms, experiments, or platform bugs | Open an issue in the [SkyEngine system repository](https://github.com/dayu-autostreamer/skyengine/issues). |
| Website content, navigation, or translation | Use [website issues](https://github.com/dayu-autostreamer/skyengine-homepage/issues). |
| Contributions, design discussion, or finding a reviewer | Read [Contributing](./contributing.md), then discuss the relevant issue or pull request with a [maintainer](./committee.mdx#maintainers). |
| Project exchange or research collaboration | Use the [project contacts](#project-contact) below. |

## Report a reproducible problem {#report-a-problem}

Include enough information for someone else to reproduce the behavior:

- SkyEngine version or commit, operating system, and deployment or compute configuration.
- The factory environment, instance or dataset, algorithm, relevant parameters, and random seed.
- Steps to reproduce, expected behavior, and what actually happened.
- Relevant logs, error messages, or exported run records.

For experiment results, include completion rates and simulation limits alongside timing measurements. For website issues, include the page URL, language, browser, and the affected content.
