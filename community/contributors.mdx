## Contributions across repositories {#contribution-history}

- [SkyEngine system contribution history](https://github.com/dayu-autostreamer/skyengine/graphs/contributors)
- [Documentation website contribution history](https://github.com/dayu-autostreamer/skyengine-homepage/graphs/contributors)

Contribution takes many forms. A useful review, a reproducible experiment, an improved translation, or a clear answer to a question can help other people use and develop the platform.

To correct a name or add contribution credit, open an issue in the relevant repository and include a link to the work. Use [Support & Contact](./support.mdx) if you need help choosing a channel.

## Make your first contribution {#participate}

Start with an example you can verify, a document you can clarify, or a problem you can reproduce. The [contribution guide](./contributing.md) explains the workflow for system and website changes.
